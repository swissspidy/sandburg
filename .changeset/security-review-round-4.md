---
'sandburg': patch
---

Limit the host's npm install to registry dependencies: a git, directory, URL or `file:`/`link:`/`workspace:` dependency in a project's package.json, overrides or lockfile is refused as unsupported before npm runs (such dependencies are prepared on the host even under `--ignore-scripts`). Adds mutation fuzzers for the file-channel WebSocket frame reader and the egress proxy's CONNECT parser.
