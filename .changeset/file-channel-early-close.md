A runtime whose file channel closes before it opens (a connection that fails, or a handshake the host does not answer) tries it again, up to three more times, instead of running without it. What the run read of its install's preload bundle is still told to the host: it waits for the channel, and goes over HTTP once the channel is closed. Before, those reports were dropped, and the install's next preload bundle missed the files the run read first.
